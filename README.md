# Computer Networks I

Course material for **Computer Networks I**, degree course in Computer
Science, Università degli Studi di Napoli Federico II — academic year
2026/27. Lecturer: Andrea Calì.

| | |
|---|---|
| [`slides/`](slides/) | the lectures and the labs, as PDF |
| [`container/`](container/) | the lab environment: one image with every tool the course uses |

The `container/` folder is complete from the start: you can set up the
environment right away. Slides and exercises are published as the course goes
on.

## The slides

One PDF per lecture, named after it: `L03.pdf`, `E1.pdf`. They are the ones
shown in class.

## The environment

The exercises are done inside a container prepared for the course: the
compiler, the network tools, `tshark`, a configured editor — the same on
Linux, macOS and Windows, and nothing installed on your own machine.

`container/README.md` explains how to install Docker, how to fetch the image
and how to work in it. Anybody who prefers to use their own system finds
there the list of what to install instead.
